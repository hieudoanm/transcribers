Turn video and audio into text, offline.

One Rust binary extracts the audio track with ffmpeg and transcribes it with whisper.cpp — mp4, mkv, mov, wav, mp3 and more, with no cloud and no account.

Everything happens on your machine.

Your media never leaves your disk. The model runs locally through whisper.cpp.

Fully local

No uploads, no API keys, no accounts. Audio is extracted and transcribed on your own hardware.

Four output formats

Plain text, SRT and WebVTT subtitles, or JSON with millisecond timestamps.

Models on demand

Pick tiny through large-v3 by name; missing models download once into a local cache.

One small binary

whisper.cpp is compiled in — about 1.6 MB, statically linked, only ffmpeg required.

ffmpeg pipeline

Any container ffmpeg reads — mp4, mkv, mov, wav, mp3 — is decoded to 16 kHz mono WAV before transcription.

Subtitle-ready

SRT and WebVTT output with millisecond timestamps, ready for players and video editors.

See it in action

Real CLI output — SRT subtitles straight to stdout or a file.

Install in one command

Prebuilt binaries for macOS and Linux, or build from source with Cargo. Requires ffmpeg on PATH.

Or from source: cargo install --git https://github.com/hieudoanm/transcribers transcribers (needs cmake for the whisper.cpp build). See the README for details.
